Setup

Three things switch everything on. All are in your Vercel project.

Admin passwordSetYou're signed in, so this is done.
AI keyPowers Ask Moma.
StorageNeeded for stats, feedback and these settings.

How to finish setup

  1. Storage: in Vercel open your moma-app-web project, go to Storage, choose Upstash for Redis (free plan), and connect it to this project. Vercel adds the keys for you.
  2. AI key: in Settings → Environment Variables add ANTHROPIC_API_KEY (or OPENAI_API_KEY). Optional: MOMA_MODEL to pick the model.
  3. Redeploy from the Deployments tab so the new keys take effect.
